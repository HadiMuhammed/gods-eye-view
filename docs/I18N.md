# Internationalization

God's Eye View supports six UI locales:

- English (`en`)
- Spanish (`es`)
- French (`fr`)
- German (`de`)
- Japanese (`ja`)
- Arabic (`ar`)

English is the default locale. The selected locale is stored in the browser under
`gev-locale` and is restored on the next visit. Unsupported or malformed locale
values fall back to English.

## Stable UI text

Stable application text is translated through the catalog in
`src/i18n.js`. Mark HTML elements with `data-i18n` for visible text:

```html
<span data-i18n="appTitle">GOD'S EYE VIEW</span>
```

Use `data-i18n-label` for accessibility labels. Do not put `data-i18n` on an
element that contains an icon unless the icon is preserved separately; the
language trigger is the reference pattern.

Data-layer and built-in scene names use stable IDs and are localized when their
rows or options are rebuilt. User-created scene names, callsigns, coordinates,
URLs, source names, and other source-backed identifiers are intentionally kept
unchanged.

## Dynamic text

An optional hybrid translation path is available for dynamic UI text:

1. Local catalog text is applied first.
2. Only text outside protected elements is eligible for automatic translation.
3. Translations are requested through the same-origin `/api/translate` proxy.
4. Results are cached in the browser.
5. The original English text remains visible if the provider is unavailable.

The proxy is disabled unless `TRANSLATION_API_URL` is configured. It expects a
LibreTranslate-compatible service with a `/translate` endpoint:

```env
TRANSLATION_API_URL=http://localhost:5000
TRANSLATION_API_KEY=
```

The provider key is read only by the server and is never injected into the
browser bundle. The proxy validates request size, limits batches, and applies a
per-client request limit. Do not enable automatic translation for private,
secret, or provider-restricted content.

## Adding a locale

1. Add the locale and its catalog entries to `src/i18n.js`.
2. Add a language-menu option in `index.html`.
3. Add or update focused tests in `src/i18n.test.mjs`.
4. Check all startup, layer, scene, Display, CCTV, and Context keys for coverage.
5. Run:

```bash
node --test src/i18n.test.mjs
npm run build
```

Keep stable UI translations in the catalog. Use the hybrid path only for text
that is genuinely dynamic and cannot be maintained reliably as a catalog entry.
